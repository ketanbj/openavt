# OpenAVT code and artifact map

All source paths below are relative to the repository root.

| Concern | Implementation | Closest tests |
|---|---|---|
| Public call/session API | `src/openavt/session.py`, `identity.py` | `tests/test_sdk.py` |
| Receiving request/permission gate | `src/openavt/gateway.py` | `tests/test_sdk.py`, `test_pap.py` |
| TLS engine | `src/openavt/tls.py`, `pki.py` | `tests/test_security.py` |
| Reliable audio framing and FSK | `channel.py`, `protocol.py`, `modem.py` | `tests/test_streaming.py`, `test_security.py` |
| Digital G.711 PCM modem | `src/openavt/pcm.py` | `tests/test_pcm.py` |
| QUIC and unreliable datagrams | `quic.py`, `datagram.py` | `tests/test_quic.py` |
| Enrollment and owner grants | `src/openavt/authority/` | `tests/test_authority.py` |
| PAP binding/confirmation | `src/openavt/pap/` | `tests/test_pap.py` |
| Risk checks | `src/openavt/risk.py` | `tests/test_risk.py` |
| Transport interface | `src/openavt/transports/base.py` | SDK/provider tests |
| WebRTC and provider audio | `transports/peer.py`, `webrtc.py`, `twilio.py`, `impaired.py` | `tests/test_sdk.py`, `test_twilio.py`, `test_quic.py` |
| CLI and runnable demos | `src/openavt/cli.py`, `demos/` | `tests/test_cli.py`, `test_sdk.py` |
| Package checks and release selection | `scripts/check_dist.py`, `smoke_wheel.py`, `release.py` | `test_dist.py`, `test_release.py` |

The abbreviated module paths are under `src/openavt/`; test paths are under
`tests/`. Start a new integration with the [public SDK](integration.md), rather
than copying demo provisioning into library modules. Core/SDK modules do not
import demos or the optional model integration.

## Evaluation and publication files

| File family | Ownership |
|---|---|
| `scripts/benchmark_handshake.py` | New local transport measurements; output must be a fresh ignored directory |
| `scripts/experiment_authority.py` | Local TLS/QUIC authority-continuity study with explicit negative controls |
| `docs/*verification.json`, `docs/performance/*.json` | Recorded snapshots, not live claims about a later revision |
| `docs/experiments/` | Dated authority results and compressed public raw report |
| `paper/sections/`, `paper/references.bib` | Editable research narrative and sources |
| `paper/scripts/extract_results.py` | Derives `paper/artifacts/measurements.tex` from the recorded QUIC report |
| `paper/openavt.pdf`, `paper/artifacts/build-verification.json` | Reviewed publication copy and its provenance; a new build needs updated review/hashes |
| `src/openavt/_version.py` | Generated by setuptools-scm; never hand-edit |
| `output/`, `.env`, key/database files | Local/private artifacts; not committed |

See [development](development.md) before changing evidence, and the
[paper guide](../paper/README.md) before rebuilding the manuscript.
